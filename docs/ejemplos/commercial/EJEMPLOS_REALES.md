# Ejemplos Reales - Oferta Comercial (Anónimos)

## Definición

**Oferta Comercial**: Propuesta formal con términos, condiciones, plazos y precio. Usado cuando cliente está listo para comprometerse con presupuesto.

Timeline típico: Análisis 2d → Presupuesto 3d → Oferta Comercial 2-3d → EFDT 5-10d

### 3. CONDICIONES COMERCIALES

#### Plazo de Pago
- 50% al firmar contrato (anticipo)

#### Planificación
- Análisis: Semana 1
- Implementación: Semanas 2-4

✓ Configuración completa en Therefore Online

## Elementos Clave de Oferta Comercial

### 1. CLARIDAD
- ✓ Qué se incluye exactamente
- ✓ Qué NO se incluye
- ✓ Supuestos críticos
- ✓ Duración y milestones

### 2. RESPONSABILIDADES
- ✓ Qué hace la consultoría
- ✓ Qué debe hacer el cliente
- ✓ Quién resuelve qué problemas

### 3. TÉRMINOS DE PAGO
- ✓ Total del importe
- ✓ Desglose de fases
- ✓ Fechas de pago
- ✓ Método de pago

### 4. VALIDEZ
- ✓ Fecha de vigencia
- ✓ Duración de validez (típicamente 30 días)
- ✓ Cómo aceptar

### 5. RIESGOS
- ✓ Riesgos identificados
- ✓ Probabilidad e impacto
- ✓ Plan de mitigación

## Flujo Típico

```
1. ANÁLISIS (2-3 días)
   ↓ Aprobación cliente
2. PRESUPUESTO ESTIMATIVO (3-5 días)
   ↓ Revisión cliente
3. OFERTA COMERCIAL (2-3 días)
   ↓ Firma cliente
4. EFDT DETALLADA (5-15 días)
   ↓ Aprobación cliente
5. IMPLEMENTACIÓN (5-30 días)
   ↓ Go-live
6. SOPORTE POST-IMPLEMENTACIÓN (30+ días)
```
