# Ejemplos de eForms Generados

Este directorio contiene XMLs de ejemplo generados por el módulo "Generador de eForms IA".

Los archivos aquí son para referencia y testing. Cada XML puede importarse directamente en Therefore Solution Designer.

## Formato de nombres

`TheConfiguration_<FormID>_<descripcion>.xml`

## Verificación

Antes de importar un XML en Therefore:
1. Verificar que no haya errores de validación en el JSON de componentes
2. Comprobar que el FormID no existe ya en la instancia
3. Revisar los avisos (warnings) aunque no bloqueen la importación
